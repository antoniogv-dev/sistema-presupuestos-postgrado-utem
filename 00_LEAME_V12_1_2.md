# LEA ANTES DE DESPLEGAR — v12.1.2

Esta entrega reemplaza la v12.1.1 y corrige el punto de equilibrio para incorporar matrícula y guía de tesis de forma consistente entre la plataforma y el XLSX institucional.

## Antes de reemplazar archivos

1. Conserve el `wrangler.jsonc` productivo de su repositorio actual.
2. No copie ni publique secrets de Cloudflare dentro del ZIP o GitHub.
3. Reemplace el código por el contenido completo de esta v12.1.2.
4. Restaure su `wrangler.jsonc` productivo.
5. Ejecute la instalación de dependencias y la batería `npm run quality:cloudflare` antes del despliegue productivo.

No se requiere una migración D1 adicional.

Consulte `RELEASE_V12_1_2_PUNTO_EQUILIBRIO_MATRICULA.md` y `VERIFICACION_V12_1_2_PUNTO_EQUILIBRIO.md` para el detalle técnico.
