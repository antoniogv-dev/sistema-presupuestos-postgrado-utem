# Design System v12.1.0 — UTEM Finance Light

El sistema adopta Light Mode como superficie principal y conserva Dark Mode.

## Light
- Base: `#F7F9FC`
- Cards: `#FFFFFF`
- Texto: `#101828`
- Secundario: `#667085`
- Bordes: `#E7ECF2`
- Azul: `#175CD3` / `#2563EB`
- Verde: `#039855`
- Ámbar: `#DC6803`
- Rojo: `#D92D20`

## Dark
- Base: `#090D14`
- Cards: `#111827`
- Texto: `#F8FAFC`
- Secundario: `#94A3B8`
- Azul: `#60A5FA`
- Verde: `#10B981`

## Principios
- Números financieros siempre tabulares.
- Tablas compactas y de lectura horizontal estable.
- Transiciones de 150 ms sin rebotes.
- Sombras sólo de profundidad mínima.
- Cards con radio 13–14 px y bordes de 1 px.
- El modo oscuro es una representación completa, no una inversión automática de colores.
